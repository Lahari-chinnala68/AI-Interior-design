# AI Interior Design Project

## Overview

AI Interior Design is a frontend web application that helps users visualize room makeover ideas. Users can upload an empty room image, choose an interior style, and view three design suggestions.

## Features

* Upload room image preview
* Select interior style:
  * Modern
  * Luxury
  * Minimal
* Generate 3 room design inspirations
* Responsive and simple user interface
* Fast frontend-based demo project

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Project Structure

```text
AI-Interior-Design/
│── index.html
│── style.css
│── script.js
```

## How to Run

1. Download or clone the project.
2. Open `index.html` in any browser.
3. Upload a room image.
4. Select style.
5. Click **Generate Design**.
